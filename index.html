About the Data

Verdicts: GO / CAUTION / OFF WATER use the limits selected above (Seniors or Novices). Day verdicts use each day's strongest forecast wind and gusts, which usually come in the afternoon.

Lightning / CAPE: CAPE above 1000 J/kg = clear the water. Use the Blitzortung button for live strike maps.

Tides: Forecast sea level off Fremantle from Open-Meteo's ocean model (tide plus weather effects), shown relative to mean sea level. It is a model forecast, not the official tide table — check BOM tide tables for anything critical. All other venues are freshwater.

Wind: Forecast from Open-Meteo. Live observations from the nearest BOM station (named above); the status banner uses whichever of forecast or live wind is worse.

Daylight: First and last light are civil twilight (sun 6° below the horizon), calculated in the page.

Data: Open-Meteo · Auto-refreshes every 10 min while open.
